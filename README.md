# SpendWise Dashboard Shell — PLP Week 4

A responsive static personal finance dashboard built for the Power Learn Project Week 4 assignment. This project demonstrates modern CSS layout techniques using Grid and Flexbox. It is a visual layout only; JavaScript functionality is not required.

## Files
- **index.html** — semantic dashboard structure, sidebar navigation, header, account summary, six spending category cards, recent transactions and reminder panel.
- **style.css** — theme variables, Grid and Flexbox layouts, responsive styles, hover/focus micro-interactions and optional dark theme.

## Requirements completed
- Sidebar/navigation menu and dashboard header.
- Six realistic static spending categories: Food, Transport, Rent, Entertainment, Savings and Utilities.
- CSS Grid for the overall page, summary area, category cards and lower content.
- Flexbox for navigation, header actions, card details and transaction rows.
- CSS custom properties in `:root` for brand, accent, background, text and secondary text colours.
- Responsive single-column layout below 768px.
- Category cards support keyboard focus and have 200ms hover/focus transitions.
- Optional dark theme using `@media (prefers-color-scheme: dark)`.

## Run the project
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Resize the browser to test the mobile layout.

The figures are sample static content. Google Fonts require an internet connection.
